## 2025-02-28 - Add Tooltip to Disabled Attach Button
**Learning:** When a button is disabled due to a specific game condition (like insufficient funds), users can get confused if there is no feedback explaining *why*. A tooltip provides immediate context and improves usability without cluttering the UI.
**Action:** When disabling interactive elements based on game state (e.g., finance), provide a helpful `tooltip` explaining the reason.
