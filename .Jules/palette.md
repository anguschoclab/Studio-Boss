## 2024-05-24 - Added aria-hidden to decorative icons in Radix/Shadcn wrappers
**Learning:** Even if a parent container (like `<li>` in Breadcrumbs or `<div>` in ResizableHandle) sets accessibility roles or manages ARIA state, dynamically rendered SVG icons (like Lucide React components `<ChevronLeft>`, `<GripVertical>`) may still be parsed by some screen readers if they lack an explicit `aria-hidden="true"`. This causes redundant or confusing announcements.
**Action:** Always explicitly add `aria-hidden="true"` to purely decorative SVGs/icons in UI components, even when the parent element acts as the accessible wrapper or state manager.
