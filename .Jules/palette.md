## 2024-03-20 - Missing aria-hidden on decorative icons in Radix/Shadcn wrappers\n**Learning:** When updating Shadcn or Radix UI wrapper components (like `Dialog`, `DropdownMenu`, `Checkbox`), decorative SVG icons (e.g., `<Check>`/`<Circle>`/`<ChevronRight>` in state indicators) often omit `aria-hidden="true"`. This causes redundant or confusing screen reader announcements, especially since the parent elements typically manage the actual ARIA state (like `aria-checked`).\n**Action:** Always ensure that decorative `lucide-react` icons explicitly include `aria-hidden="true"` to prevent screen reader audio clutter.
